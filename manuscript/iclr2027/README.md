# ICLR 2027 submission source

Compile the anonymous submission PDF with `latexmk -pdf main.tex`.

This tree uses the official ICLR 2027 style files retrieved on 2026-09-15.
The generic manuscript remains under `manuscript/`; this tree is the dedicated
page-budgeted anonymous submission version. Do not upload `baseline/`, which is
only the faithful pre-compression page-count record. Before submission, authors
must confirm the AI-use disclosure and run the anonymity audit on the exact
upload bundle.
